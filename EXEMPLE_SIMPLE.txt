INSTRUCTIONS POUR TESTER:

1. Créer un nouveau fichier dans Microsoft Excel ou Calc

2. Dans la première ligne, taper exactement:
   N°	Nom Prénom	Matricule	Classe	Année	MG	ECTS
   (Les données sont séparées par des tabulations)

3. Copier les 5 lignes de données ci-dessus dans le fichier

4. Sauvegarder le fichier en .xlsx ou .xls
   (File → Save As → Format Excel)

5. Lancer l'application PV Délibération

6. Aller dans l'onglet "📥 Import Excel"

7. Cliquer "Parcourir" et sélectionner votre fichier

8. Cliquer "✅ Charger et valider le fichier"

9. Vérifier que:
   ✅ Les 5 étudiants apparaissent dans le tableau
   ✅ La colonne MG affiche les moyennes (14.5, 12.0, 10.8, etc.)
   ✅ La colonne Décision affiche Admis/Rattrapage/Refusé
   ✅ Message "✅ Import réussi avec 5 étudiants" en bas
