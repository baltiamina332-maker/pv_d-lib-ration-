7. COMMON ISSUES & SOLUTIONS

ISSUE 1: Build fails with CS errors
  Cause: Project not properly configured
  Solution:
    1. Clean Solution (Build → Clean)
    2. Rebuild Solution
    3. Ensure all files saved

ISSUE 2: Email field not visible in form
  Cause: XAML not compiled correctly
  Solution:
    1. Close Visual Studio
    2. Delete bin/ and obj/ folders
    3. Reopen solution
    4. Rebuild

ISSUE 3: Email validation not working
  Cause: Code-behind changes not applied
  Solution:
    1. Check MainWindow.xaml.cs was saved
    2. Verify BtnAddUser_Click method has email logic
    3. Rebuild solution

ISSUE 4: Email column not showing in list
  Cause: XAML DataGrid changes not applied
  Solution:
    1. Check MainWindow.xaml saved
    2. Verify DataGrid has Email column defined
    3. Rebuild solution

ISSUE 5: Application crashes on add user
  Cause: User model missing Email property or DB issue
  Solution:
    1. Check Models/User.cs has Email property ✅ (verified)
    2. Check database has email column
    3. Run: ALTER TABLE users ADD COLUMN email VARCHAR(255) NULL;
