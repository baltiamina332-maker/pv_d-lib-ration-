  ÉTAPE 2 : MODIFIER LA BASE DE DONNÉES (3 minutes)
═══════════════════════════════════════════════════════════════════════════

Ouvrir PhpMyAdmin, MySQL Workbench, ou votre outil MySQL préféré.

Coller et exécuter CES 3 COMMANDES (l'une après l'autre) :

┌─ COMMANDE 1 : Ajouter colonne email
│
│  ALTER TABLE users ADD COLUMN email VARCHAR(255) NULL DEFAULT '';
│
└─────────────────────────────────────────────────────────────────────

┌─ COMMANDE 2 : Créer table historique
│
│  CREATE TABLE IF NOT EXISTS deliberations (
│      id INT AUTO_INCREMENT PRIMARY KEY,
│      date_deliberation DATETIME NOT NULL,
│      nb_etudiants INT NOT NULL,
│      nb_admis INT NOT NULL,
│      nb_ajournes INT NOT NULL,
│      fichier_pv VARCHAR(500) NOT NULL,
│      utilisateur_id INT,
│      FOREIGN KEY (utilisateur_id) REFERENCES users(id) ON DELETE SET NULL
│  );
│
└─────────────────────────────────────────────────────────────────────

┌─ COMMANDE 3 : Vérifier que tout est OK
│
│  SELECT COUNT(*) as nb_colonnes FROM INFORMATION_SCHEMA.COLUMNS 
│  WHERE TABLE_NAME = 'users' AND COLUMN_NAME = 'email';
│  
│  (doit afficher 1)
│
└─────────────────────────────────────────────────────────────────────

✅ Les 3 commandes exécutées sans erreur = SUCCÈS !

❌ PROBLÈME 1 : "HistoriqueService not found" lors de la compilation
───────────────────────────────────────────────────────────────────

  SOLUTION :
  
  1. Fermer Visual Studio COMPLÈTEMENT (alt+F4 ou File → Exit)
  
  2. Ouvrir l'Explorateur Windows
  
  3. Aller dans le dossier du projet
  
  4. Supprimer ces 2 dossiers (attention : c'est important !)
     - bin
     - obj
  
  5. Rouvrir Visual Studio et le projet
  
  6. Build → Rebuild Solution

---

❌ PROBLÈME 2 : Erreur lors de l'exécution de la commande SQL
──────────────────────────────────────────────────────────────

  Message type : "Table 'users' doesn't exist" ou "Duplicate column"
  
  SOLUTION :
  
  1. Vérifier que vous êtes connecté à la BONNE base de données
  
  2. Vérifier que la table 'users' existe :
     SELECT * FROM users LIMIT 1;
  
  3. Si 'users' n'existe pas : créer d'abord la table users
  
  4. Si la colonne 'email' existe déjà : pas grave, ignore l'erreur
  
  5. Réessayer les commandes SQL

---

❌ PROBLÈME 3 : L'application se lance mais pas de données
────────────────────────────────────────────────────────────

  SOLUTION :
  
  1. Vérifier la connexion à la BD
  
  2. Lancer l'application et regarder la console Visual Studio
  
  3. Chercher les messages d'erreur
  
  4. Vérifier les tables MySQL existent :
     SHOW TABLES;

---

❌ PROBLÈME 4 : Email ne s'affiche pas dans le DataGrid
─────────────────────────────────────────────────────────

  SOLUTION :
  
  1. Vérifier la colonne 'email' a été ajoutée :
     DESCRIBE users;
  
  2. Si elle n'existe pas, exécuter la première commande SQL encore
  
  3. Fermer et relancer l'application

---

❌ PROBLÈME 5 : L'historique reste vide
───────────────────────────────────────

  SOLUTION :
  
  1. Vérifier que la table 'deliberations' existe :
     SHOW TABLES;
  
  2. Si elle n'existe pas, exécuter la deuxième commande SQL
  
  3. Générer un PV et attendre que le DataGrid se remplisse
  
  4. Si toujours vide : regarder les erreurs dans la console Visual Studio
