🔴 CRITICAL DECISION: Multiple Rescue Conditions Priority

⚠️  THIS IS THE MOST IMPORTANT DECISION ⚠️

THE ISSUE:
──────────
When a student qualifies for MULTIPLE rescue conditions simultaneously,
the system must decide which one to apply.

CONCRETE EXAMPLE:
─────────────────
Student: Name = Jean, Status = Ancien (returning), MG = 9.8, ECTS = 18

This student qualifies for:
  ✅ Rule A: Ancien AND MG ≥ 9.7
  ✅ Rule C: MG ≥ 8.0 AND Moyenne_UE ≥ 7.0

PROBLEM:
────────
If we just say "apply first matching condition", the result depends on
the ORDER we check the conditions in the code:

  Scenario 1: Check Rule A first → Mention = "Rachat validé (Ancien)"
  Scenario 2: Check Rule C first → Mention = "Rachat UE validé"

SAME STUDENT, DIFFERENT DECISION!

This is NOT a fair business rule. It's an arbitrary implementation choice.
