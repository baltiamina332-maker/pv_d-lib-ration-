📋 WHAT WAS IMPLEMENTED:

✅ Format 2 Support
   - Read Excel files with: N°, Nom, Matricule, Classe, Année, Module, CC, TP, Examen, Crédit
   - Support multiple modules per student (grouped by Matricule)
   - Example: Student has 3 rows (Math, Physics, Chemistry)

✅ Automatic Average Calculation
   - Formula: MG = Σ(Module_Average × Credit) / Σ(Credit)
   - Where: Module_Average = (CC + TP + Examen) / 3
   - Example: Math (14+13+15)/3 = 14.00 × 4 credit = 56 (weighted)

✅ Auto-Format Detection
   - Reads Excel header to detect format
   - Format 1 (MG pre-calculated): MG = 13.5
   - Format 2 (Calculate from grades): CC=14, TP=13, Exam=15
   - No user configuration needed - automatic!

✅ Decision Application
   - MG ≥ 12.0  → ADMIS (🟢)
   - 10.0 ≤ MG < 12.0 → RATTRAPAGE (🟡)
   - MG < 10.0 → REFUSÉ (🔴)

✅ Console Logging
   - Detailed calculation steps shown
   - Verification of results
   - Debugging support

📈 CALCULATION EXAMPLE (Jean Dupont):

Input:
  Module 1 (Math):     CC=14, TP=13, Examen=15, Crédit=4
  Module 2 (Physics):  CC=12, TP=11, Examen=13, Crédit=3
  Module 3 (Chemistry):CC=10, TP=9,  Examen=11, Crédit=2

Step 1 - Module Averages:
  Math:     (14+13+15)/3 = 14.00
  Physics:  (12+11+13)/3 = 12.00
  Chemistry:(10+9+11)/3  = 10.00

Step 2 - Weighted Sum:
  Math:     14.00 × 4 = 56.00
  Physics:  12.00 × 3 = 36.00
  Chemistry:10.00 × 2 = 20.00

Step 3 - Overall Average (MG):
  MG = (56.00 + 36.00 + 20.00) / (4 + 3 + 2)
  MG = 112.00 / 9
  MG = 12.44 ✓

Step 4 - Decision:
  MG (12.44) ≥ 12.0 → ADMIS 🟢

Console Output Shows All Steps Above!
