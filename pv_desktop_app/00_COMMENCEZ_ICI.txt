                    🚀 DÉMARRER EN 3 ÉTAPES
════════════════════════════════════════════════════════════════════════════════

ÉTAPE 1 - Démarrer MySQL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ouvrez XAMPP Control Panel
2. Trouvez MySQL
3. Cliquez "Start" si pas démarré
4. Vérifiez qu'il affiche "ON" ✅

→ Si vous n'avez pas XAMPP:
  Téléchargez: https://www.apachefriends.org/download.html


ÉTAPE 2 - Lancer l'Application
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Double-cliquez sur:
  F:\pv de deliberation\bin\Debug\DesktopApp.exe

Ou depuis PowerShell:
  cd "F:\pv de deliberation"
  .\bin\Debug\DesktopApp.exe

→ L'application devrait s'ouvrir en 2-3 secondes


ÉTAPE 3 - Importer des Données
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cliquez l'onglet: "📥 Import Excel"
2. Cliquez: "Parcourir..." (bouton orange)
3. Sélectionnez votre fichier Excel
4. Cliquez: "✅ Charger et valider le fichier" (bouton vert)
5. Regardez les données s'afficher! 🎉

Connexion MySQL:

  Port:        3306
  Base:        pv_deliberation

  Mot passe:   (vide)

Si votre MySQL est ailleurs, modifiez App.config:
  1. Ouvrez: F:\pv de deliberation\App.config
  2. Cherchez: <add name="MySqlConnection"...
  3. Modifiez: Server=, Port=, User Id=, Password=
  4. Sauvegardez et relancez l'application

════════════════════════════════════════════════════════════════════════════════
                    📁 FORMAT FICHIER EXCEL REQUIS
════════════════════════════════════════════════════════════════════════════════

Votre fichier Excel DOIT avoir cette structure:

Ligne 1 (EN-TÊTES):
  A: id_etudiant
  B: nom
  C: prenom
  D: matricule
  E: classe_groupe
  F-H: (optionnel - id_session, type_session, annee_universitaire)
  I: moyenne_generale  ← IMPORTANT: Colonne I avec les moyennes!

Ligne 2+ (DONNÉES):
  1 | Martin | Jean | MAT001 | L3-GROUPE1 | ... | 14.5
  2 | Dupont | Marie | MAT002 | L3-GROUPE1 | ... | 9.2
  3 | ...

REGLES IMPORTANTES:
  ✓ Pas de lignes vides dans les données
  ✓ Colonnes A à E et I obligatoires
  ✓ Les moyennes (colonne I) doivent être des NOMBRES
  ✓ La ligne 1 doit contenir les en-têtes
  ✓ Format fichier: .xlsx ou .xls

                    ❓ PREMIERS PAS - QUESTIONS FRÉQUENTES
════════════════════════════════════════════════════════════════════════════════

Q: L'application ne démarre pas
A: Vérifiez que .NET Framework 4.8 est installé:
   https://dotnet.microsoft.com/download/dotnet-framework

Q: "Base de données : Déconnectée"
A: MySQL n'est pas en cours d'exécution:
   1. Ouvrez XAMPP Control Panel
   2. Cliquez "Start" pour MySQL
   3. Relancez l'application

Q: Import échoue
A: Vérifiez que:
   1. Le fichier Excel n'est pas ouvert dans Excel
   2. La colonne I contient les moyennes en NOMBRES
   3. Le format est .xlsx

Q: Comment modifier la configuration MySQL?
A: Ouvrez App.config et changez la connection string

Q: Où sont les PV générés?
A: Fonctionnalité en développement (Phase 2)

→ Plus de réponses: Consultez TROUBLESHOOTING.md
