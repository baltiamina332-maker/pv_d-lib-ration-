LE PROBLÈME (Problem Found!)
═════════════════════════════════════════════════════════════════════════

Le message "Total: 2" signifiait que 2 étudiants ÉTAIENT importés,
mais seulement 1 était VISIBLE dans le tableau.

Cause:
- Le TextBlock "Aucune donnée chargée..." était positionnées APRÈS 
  le DataGrid dans le code XAML
- Il recouvrait donc l'affichage du DataGrid
- Quand on importait des données, le placeholder n'était pas correctement
  caché, bloquant la vue de la 2ème ligne


LA SOLUTION (Solution Applied!)
═════════════════════════════════════════════════════════════════════════

Trois changements ont été faits:

1. RÉORGANISER L'ORDRE DES ÉLÉMENTS
   └─ Déplacer le TextBlock AVANT le ScrollViewer dans le XAML
   
2. AJOUTER Z-INDEX (Layering)
   ├─ TextBlock: Panel.ZIndex="1"  (arrière-plan)
   └─ ScrollViewer: Panel.ZIndex="10"  (avant-plan)
   
3. AUGMENTER LA TAILLE
   ├─ MinHeight: 300 → 400 (plus d'espace)
   └─ MaxHeight: 600 (limite supérieure)

   ├─ Ouvrez le fichier créé
   ├─ Si les 2 lignes sont dans l'export, c'est juste un bug d'affichage
   └─ Si seulement 1 ligne, c'est un bug d'import
