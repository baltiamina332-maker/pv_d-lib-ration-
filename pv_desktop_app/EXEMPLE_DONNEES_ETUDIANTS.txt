═══════════════════════════════════════════════════════════════════════════════
COMMENT CRÉER LE FICHIER DANS EXCEL
═══════════════════════════════════════════════════════════════════════════════

1. Ouvrir Excel
2. Créer les colonnes dans la ligne 1:
   Colonne A: N°
   Colonne B: Nom Prénom (ou simplement Nom si séparé)
   Colonne C: Matricule (ou Prénom si format séparé)
   Colonne D: Classe (ou Matricule si format séparé)
   Colonne E: Année (ou Classe si format séparé)
   Colonne F: MG ← OBLIGATOIRE (ou Année si format séparé)
   Colonne G: ECTS (ou MG si format séparé)
   Colonne H: (ou ECTS si format séparé)

3. Remplir les données à partir de la ligne 2
4. Sauvegarder en format Excel (.xlsx)
5. Importer dans l'application


═══════════════════════════════════════════════════════════════════════════════
⚠️  POINTS IMPORTANTS
═══════════════════════════════════════════════════════════════════════════════

✓ La colonne MG DOIT être remplie
✓ Format de la moyenne: 13.5 (point comme séparateur, pas virgule)
✓ Pas de lignes vides entre les données
✓ Les en-têtes doivent correspondre aux colonnes attendues
✓ ECTS doit être un nombre entier (28, pas 28.5)
✓ La première ligne doit contenir les en-têtes
✓ Les données commencent à partir de la ligne 2


═══════════════════════════════════════════════════════════════════════════════
ERREURS FRÉQUENTES ET SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

❌ "Impossible de charger le fichier"
✓ Vérifiez que le fichier existe et est en format Excel (.xlsx ou .xls)

❌ "Aucune donnée trouvée"
✓ Vérifiez que les données commencent à la ligne 2
✓ Vérifiez qu'il n'y a pas de lignes vides

❌ "Erreur de format"
✓ Vérifiez les en-têtes: N°, Nom Prénom, Matricule, Classe, Année, MG, ECTS
✓ Vérifiez que MG est un nombre (13.5) et pas du texte

❌ "Moyenne non trouvée"
✓ Vérifiez que la colonne MG contient des données
✓ Vérifiez le format: utiliser le point (.) et pas la virgule (,)

❌ "Aucune décision calculée"
✓ Vérifiez que MG n'est pas vide
✓ Vérifiez que le service DecisionCalculatorService fonctionne


═══════════════════════════════════════════════════════════════════════════════
PROPRIÉTÉS DE LA CLASSE ÉTUDIANT UTILISÉES
═══════════════════════════════════════════════════════════════════════════════

- Id: ID unique de l'étudiant
- NumeroOrdre: Numéro d'ordre (colonne A)
- Nom: Nom de l'étudiant (extrait de NomPrenom si combiné)
- Prenom: Prénom de l'étudiant (extrait de NomPrenom si combiné)
- NomPrenom: Nom et prénom complets
- Matricule: Identifiant unique (ex: MAT001)
- ClasseGroupe: Classe ou groupe (ex: L1 Info)
- AnneeUniversitaire: Année (ex: 2025/26)
- MoyenneGenerale: Moyenne générale (MG) - UTILISÉE POUR DÉCISION
- EctsValides: ECTS validés
- EctsTotal: Total ECTS (par défaut 30)
- Decision: Décision calculée (Admis / Rattrapage / Refusé)
- Mention: Mention académique (optionnel)
