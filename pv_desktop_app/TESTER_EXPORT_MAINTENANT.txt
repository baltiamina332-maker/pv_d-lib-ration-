  3. TESTER EXPORT

1. Onglet "Import Excel"

2. Cliquer "Parcourir"
   → Sélectionner: donnees_test.xlsx

3. Cliquer "Charger et valider le fichier"
   → Les données s'affichent dans le grid
   → Le bouton "Exporter en Excel" s'active (rouge)

4. Cliquer "💾 Exporter en Excel"
   → Message: "Export réussi!"
   → Demande: "Voulez-vous ouvrir le fichier?"

5. Cliquer "Oui"
   → Fichier s'ouvre dans Excel ✓

════════════════════════════════════════════════════════════════════════════════
  4. VÉRIFIER LE FICHIER CRÉÉ
════════════════════════════════════════════════════════════════════════════════

Fichier: Etudiants_[Classe]_[Date_Heure].xlsx

Exemple: Etudiants_3INFO-A_2026-07-27_143025.xlsx
