Comment utiliser:
1. Copier les données ci-dessous

5. Importer dans l'application avec le bouton "Charger Excel"
6. L'application devrait détecter le format automatiquement

COMMENT COPIER-COLLER DANS EXCEL:

Méthode 1 (Recommandée):
1. Sélectionner le texte ci-dessus (EN-TÊTES + DONNÉES)
2. Copier (Ctrl+C)
3. Créer un nouveau fichier Excel
4. Cliquer sur la cellule A1
5. Coller (Ctrl+V)
6. Excel va auto-formater les colonnes séparées par des tabulations

Méthode 2 (Alternative):
1. Créer un nouveau fichier Excel
2. Entrer manuellement les en-têtes ligne 1
3. Remplir les données à partir de la ligne 2
4. Sauvegarder

Méthode 3 (Depuis un fichier texte):
1. Copier ce contenu dans un fichier text: format2_test.txt
2. Ouvrir Excel
3. Data → From Text (ou Get External Data)
4. Sélectionner le fichier
5. Choisir "Tab Delimited"
6. Importer

═════════════════════════════════════════════════════════════════════════════════════════════════

IMPORTANT:
- Les colonnes doivent être séparées par des TABULATIONS (pas d'espaces)
- Les décimales doivent être des points (14, pas 14,0)
- La première ligne doit contenir exactement: N°, Nom Prénom, Matricule, Classe, Année, Module, CC, TP, Examen, Crédit
- Chaque module du même étudiant doit avoir le même N°, Nom Prénom, Matricule, Classe, Année
