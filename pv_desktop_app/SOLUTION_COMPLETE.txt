ERREUR CORRIGÉE:
───────────────

❌ AVANT: "Aucune surcharge pour la méthode 'Create' n'accepte les arguments 1"

CAUSE: Mauvaise utilisation de l'API DocumentFormat.OpenXml
        WordprocessingDocument.Create() nécessite 2 paramètres:
        1. Stream (FileStream)
        2. WordprocessingDocumentType (type de document)

✅ APRÈS: Correction appliquée dans Services/WordGenerationService.cs

Code corrigé:
─────────────

// ❌ AVANT (incorrect)
using DocX = DocumentFormat.OpenXml.Packaging.WordprocessingDocument;
using (DocX wordDocument = DocX.Create(fileStream))  // Manque le type!
{
    var doc = wordDocument.MainDocumentPart.Document;
}

// ✅ APRÈS (correct)
using DocumentFormat.OpenXml.Packaging;
using (WordprocessingDocument wordDocument = 
       WordprocessingDocument.Create(fileStream, WordprocessingDocumentType.Document))
{
    var mainPart = wordDocument.AddMainDocumentPart();
    mainPart.Document = new Document();
    var body = new Body();
    mainPart.Document.AppendChild(body);
}
