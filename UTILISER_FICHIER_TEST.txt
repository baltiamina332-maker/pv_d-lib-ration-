SI VOUS AVEZ VOTRE PROPRE FICHIER:
──────────────────────────────────

Au lieu d'utiliser donnees_test.xlsx, vous pouvez utiliser votre propre fichier.

Assurez-vous que:
✓ Le fichier est en format .xlsx (pas .csv, .xls, .ods)
✓ Le fichier a 7 colonnes: N°, Nom Prénom, Matricule, Classe, Année, MG, ECTS
✓ Les données commencent ligne 2 (ligne 1 = en-têtes)
✓ MG est un nombre (10.5, pas "10.5")
✓ ECTS est un nombre (12, pas "12")
✓ Le fichier n'est pas ouvert dans Excel
✓ Le fichier est accessible (pas sur un lecteur réseau inaccessible)


TROUBLESHOOTING:
────────────────

Si vous avez une erreur lors du chargement:

❌ "Le fichier ne contient pas assez de colonnes"
   → Vérifiez que vous avez 7 colonnes (A-G)

❌ "Le fichier est verrouillé"
   → Fermez le fichier dans Excel et réessayez

❌ "Aucune donnée valide trouvée"
   → Vérifiez qu'il y a une ligne 2 avec des données

❌ "Valeur non valide pour MG"
   → Vérifiez que MG est un nombre (pas du texte)

Si le problème persiste:
1. Utilisez le fichier de test (donnees_test.xlsx) pour vérifier que le système fonctionne
2. Consultez FORMAT_EXCEL_REQUIS.md pour le format exact
3. Consultez SOLUTION_IMPORT_EXCEL.md pour les solutions détaillées
