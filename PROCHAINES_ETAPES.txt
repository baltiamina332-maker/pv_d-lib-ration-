📍 ÉTAPE 1: AJOUTER LE BOUTON

   Ouvre: MainWindow.xaml

   Cherche cette ligne (section Import):
   ┌─────────────────────────────────────────────┐
   │ <Button Name="btnChargerExcel"              │
   │         Content="Charger et valider..."      │
   └─────────────────────────────────────────────┘

   AVANT cette ligne, ajoute:

   ┌─────────────────────────────────────────────────────────┐
   │ <Button Name="btnGenererExcelDepuisBase"               │
   │         Click="BtnGenererExcelDepuisBase_Click"        │
   │         Style="{StaticResource PrimaryButton}"         │
   │         Content="📊 Créer Excel depuis Base"           │
   │         Margin="5,5,5,5"                               │
   │         ToolTip="Crée etudiant.xlsx depuis BD"/>      │
   └─────────────────────────────────────────────────────────┘

   Sauvegarde le fichier (Ctrl+S)

🧪 ÉTAPE 3: TESTER

   1. Lance l'app (F5)
   
   2. Tu devrais voir le bouton:
      "📊 Créer Excel depuis Base"
   
   3. Clique dessus
   
   4. Attends quelques secondes
   
   5. Message: "✓ Fichier créé!"
   
   6. Clique "Oui" (pour ouvrir) ou "Non"
   
   7. Vérifie le fichier existe:
      C:\Users\[TonNom]\Documents\etudiant.xlsx
   
   8. Teste l'import:
      - Clique "Parcourir"
      - Cherche Documents/etudiant.xlsx
      - Sélectionne et clique "Ouvrir"
      - Clique "Charger et valider"
      - Données apparaissent ✓
   
   9. Génère le PV:
      - Clique "Générer PV"
      - Le PV se crée ✓
