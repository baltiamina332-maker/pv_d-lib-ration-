4. DECISION RULES (Automatically Applied)
───────────────────────────────────────────────────────────────────────────────

IF MG ≥ 10:
  • ECTS ≤ 15          → ADMIS
  • 15 < ECTS ≤ 22     → DECISION CONSEIL
  • ECTS > 22          → ADMIS AVEC MODERATION

IF MG < 10:
  • ECTS > 22          → REDOUBLE / EXCLU
  • ECTS ≤ 22          → CONSEIL D'ECOLE (or ADMIS with buyback check)

SPECIAL CONDITIONS (buyback eligibility):
  • Veteran students:  MG ≥ 9.7 AND MG ≥ 8 AND Moyenne UE ≥ 7
  • New students:      MG ≥ 9.5 AND MG ≥ 8 AND Moyenne UE ≥ 7

MENTIONS:
  • MG ≥ 14   → TRES BIEN
  • MG ≥ 12   → BIEN
  • MG ≥ 10   → ASSEZ BIEN
  • MG < 10   → PASSABLE (or no mention)

5. EXCEL IMPORT FORMAT
───────────────────────────────────────────────────────────────────────────────

Column A: N° (number)
Column B: Nom et Prénom OR just Nom (name)
Column C: Prénom (if separated) OR Matricule (if combined)
Column D: Matricule (if separated) OR Classe/Groupe
Column E: Classe/Groupe (if separated) OR Année Universitaire
Column F: Année Universitaire (if separated) OR Moyenne Générale (MG)
Column G: Moyenne Générale (if separated) OR ECTS
Column H: ECTS (if separated)

→ Application auto-detects format based on column content

8. ERROR MESSAGES AND SOLUTIONS
───────────────────────────────────────────────────────────────────────────────

RED FIELD IN LOGIN:
  → Invalid characters or empty field
  → Check username/password requirements
  → Username: 3+ chars, letters/numbers/._- only

FILE LOCKED ERROR:
  → Excel file is open in another program
  → Close the file and try again
  → Application will retry 3 times automatically

DATABASE CONNECTION FAILED:
  → Check MySQL server is running
  → Verify connection credentials in App.config
  → Ensure database and tables exist

EMPTY DATAGRID AFTER IMPORT:
  → Excel file format incorrect
  → Check column order matches specification
  → Verify numbers are valid (not text)
