   → Script SQL pour créer la table deliberations

MODIFICATIONS EXISTANTES:

1. MainWindow.xaml.cs
   → Ajout: historiqueService (initialisation)
   → Ajout: LoadHistorique() (charge les données)
   → Ajout: RefreshHistorique() (rafraîchit les données)
   → Modification: GenererPVWord() (enregistre dans l'historique)

COMMENT ÇA FONCTIONNE
═══════════════════════════════════════════════════════════════════════════════

FLUX D'UTILISATION:

1. Utilisateur ouvre l'onglet "Historique"
   ↓
2. LoadHistorique() charge les données de la BD
   ↓
3. HistoriqueService.GetAllHistorique() récupère tous les PV
   ↓
4. DataGrid se remplit avec les données
   ↓
5. Utilisateur génère un nouveau PV
   ↓
6. GenererPVWord() enregistre dans deliberations
   ↓
7. LoadHistorique() se rafraîchit
   ↓
8. Historique affiche le nouveau PV

POUR FAIRE FONCTIONNER
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: CRÉER LA TABLE (5 min)
─────────────────────────────

Exécuter en MySQL/phpMyAdmin:

  CREATE TABLE IF NOT EXISTS deliberations (
      id INT PRIMARY KEY AUTO_INCREMENT,
      date_deliberation DATETIME DEFAULT CURRENT_TIMESTAMP,
      nb_etudiants INT NOT NULL DEFAULT 0,
      nb_admis INT NOT NULL DEFAULT 0,
      nb_ajournes INT NOT NULL DEFAULT 0,
      fichier_pv VARCHAR(500) NOT NULL,
      utilisateur_id INT
  );

ÉTAPE 2: COMPILER (5 min)
─────────────────────────

Visual Studio:
  Build → Clean Solution
  Build → Rebuild Solution
  
Attendre: ~2-3 minutes

ÉTAPE 3: TESTER (5 min)
──────────────────────

1. Run DesktopApp.exe
2. Login: admin / admin123
3. Import Excel: donnees_test.xlsx
4. Génération PV: Cliquer "Générer PV"
5. Onglet Historique: Vérifier nouvelle ligne s'affiche
6. ✅ Done!

═══════════════════════════════════════════════════════════════════════════════
STRUCTURE DE LA TABLE deliberations
═══════════════════════════════════════════════════════════════════════════════

Colonne              Type          Description
────────────────────────────────────────────────────
id                   INT           Clé primaire auto-incrémentée

DÉPANNAGE
═══════════════════════════════════════════════════════════════════════════════

Problème: Historique vide après génération
Solution:
  1. Vérifier table existe: SHOW TABLES LIKE 'deliberations';
  2. Si absent: Exécuter CREATE TABLE... (voir ÉTAPE 1)
  3. Redémarrer l'app

Problème: "Erreur lors du chargement de l'historique"
Solution:
  1. Vérifier MySQL Server en cours d'exécution
  2. Vérifier App.config avec bons identifiants
  3. Tester connexion: SELECT 1;

Problème: Onglet Historique n'existe pas
Solution:
  1. Fermer Visual Studio
  2. Supprimer bin/ et obj/
  3. Recompiler
