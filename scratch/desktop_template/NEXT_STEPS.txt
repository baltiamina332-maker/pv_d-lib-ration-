PROBLÈME ACTUEL:
────────────────

Le projet Framework 4.8 WPF ne compile pas avec 'dotnet build' car la compilation des 
fichiers XAML nécessite Visual Studio ou MSBuild, pas dotnet CLI.

→ SOLUTION: Ouvrir dans Visual Studio 2022 ou utiliser le batch file fourni.


COMMENT PROCÉDER MAINTENANT:
──────────────────────────

OPTION A: VISUAL STUDIO (RECOMMANDÉ)
────────────────────────────────────

1. Ouvrez DesktopApp.sln dans Visual Studio 2022 ou 2019
   
2. Visual Studio compilera automatiquement:
   - Les fichiers XAML → .g.cs (code-behind généré)
   - Les services
   - Les modèles
   - Tous les fichiers C#
   
3. Build → Clean Solution
   Build → Build Solution
   
4. F5 pour exécuter et tester


OPTION B: BATCH FILE (SANS VISUAL STUDIO OUVERT)
─────────────────────────────────────────────────

1. Double-cliquez sur: COMPILER_SANS_VISUAL_STUDIO.bat

2. Le script va:
   - Trouver MSBuild automatiquement
   - Restaurer les packages NuGet
   - Compiler la solution
   - Générer l'EXE dans bin\Debug\DesktopApp.exe


OPTION C: POWERSHELL (LIGNE DE COMMANDE)
─────────────────────────────────────────

Remplacez le chemin VS si nécessaire, puis exécutez:

$msbuild = "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe"
& $msbuild DesktopApp.sln /p:Configuration=Debug /t:Build


TESTER LA FONCTIONNALITÉ COMPLÈTE:
──────────────────────────────────

Une fois compilé et l'application lancée:

1. Authentification
   └─ Connexion avec les identifiants admin

2. Import Excel
   └─ Allez à l'onglet "Import Excel"
   └─ Chargez un fichier Excel avec les colonnes: N°, Nom et Prénom, Matricule, 
      Classe/Groupe, Année Univ., MG, ECTS
   └─ Les données s'affichent dans le DataGrid avec calcul automatique des décisions/mentions

3. Générer PV Word
   └─ Cliquez sur "Générer PV"
   └─ Un document Word est généré et archivé automatiquement
   └─ Enregistré en base de données
   └─ Affiche le chemin du fichier

4. Archivage
   └─ Les fichiers sont dans: C:\Users\[VotreUtilisateur]\Documents\PV_Archives\
   └─ Cliquez "Ouvrir Archive" pour voir les PV générés

STRUCTURE DES DONNÉES - EXEMPLE:
────────────────────────────────

Étudiant avec MG=10.5, ECTS=12:
→ Admis (car MG≥10 et ECTS≤15)

Étudiant avec MG=10.2, ECTS=18:
→ Décision Conseil (car MG≥10 et 15<ECTS≤22)

Étudiant avec MG=9.8, ECTS=25:
→ Redouble/Exclu (car MG<10 et ECTS>22)

Étudiant avec MG=9.7 (ancien), ECTS=8 par UE:
→ Admis avec modération (après vérification rachat)


TROUBLESHOOTING:
───────────────

Q: "Erreur: Visual Studio n'est pas installé"
R: Installez Visual Studio Community 2022 ou utilisez le batch file

Q: "Erreur NuGet"
R: Exécutez: nuget restore DesktopApp.sln

Q: "Erreur de base de données"
R: Vérifiez DatabaseConnection.cs et la chaîne de connexion

Q: "InitializeComponent() n'existe pas"
R: Ce problème disparaît une fois compilé dans Visual Studio


DÉPLOIEMENT EN PRODUCTION:
──────────────────────────

1. Build → Release (au lieu de Debug)
2. Executables: bin\Release\DesktopApp.exe
3. Copier le dossier 'Release' sur les postes utilisateurs
