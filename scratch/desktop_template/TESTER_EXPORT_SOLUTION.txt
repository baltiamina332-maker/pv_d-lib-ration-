  SI ERREUR
════════════════════════════════════════════════════════════════════════════════

Regarder la console pour les logs d'erreur:

❌ "[EXPORT] ❌ Erreur: Pas de données à exporter"
   → Vous n'avez pas chargé de fichier Excel

❌ "[EXPORT] ❌ Erreur: Impossible de créer le dossier"
   → Problème de permissions. Essayer:
     - Redémarrer Visual Studio en admin
     - Exporter sur le Bureau au lieu de Documents

❌ "[EXPORT] ❌ Le fichier n'existe pas"
   → Vérifier l'espace disque, redémarrer l'app

❌ "[EXPORT] ❌ Exception: ..."
   → Voir le message d'exception pour détails

════════════════════════════════════════════════════════════════════════════════
  VÉRIFIER LE DOSSIER
════════════════════════════════════════════════════════════════════════════════

Si le fichier ne s'ouvre pas:

1. Ouvrir l'Explorateur Windows
2. Aller à: Mes Documents
3. Chercher le dossier: "Exports_Étudiants"
4. Double-cliquer pour l'ouvrir
5. Chercher les fichiers: Etudiants_*.xlsx

Le fichier devrait être là avec un nom comme:
  Etudiants_3INFO-A_2026-07-27_143025.xlsx

Si le dossier n'existe pas:
  → L'export a échoué. Vérifier la console pour l'erreur.
