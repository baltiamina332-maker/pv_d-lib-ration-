CSV FILE FORMAT
════════════════════════════════════════════════════════════════════════

Required columns (in order):
1.  id_etudiant         - Student ID (number)
2.  nom                 - Last name (text)
3.  prenom              - First name (text)
4.  matricule           - Registration number (text)
5.  classe_groupe       - Class/Group (text)
6.  id_session          - Session ID (number)
7.  type_session        - Session type (text, e.g., "Principale")
8.  annee_universitaire - Academic year (text, e.g., "2025-2026")
9.  moyenne_generale    - Overall GPA (decimal, e.g., "12.43")

Optional columns (will use defaults if missing):
10. ects                - ECTS credits (number, default: 30)
11. statut              - Status: "Ancien" or "Nouveau" (default: "Nouveau")
12. moyenne_ue          - UE average (decimal, default: same as MG)

KEY POINTS
════════════════════════════════════════════════════════════════════════

✓ MG values should be PRE-CALCULATED
  → Application reads and uses these values directly
  → Does NOT calculate MG from other columns

✓ ECTS is IMPORTANT for decisions
  → Example: MG ≥ 10 + ECTS ≤ 15 = "Admis"
  → Example: MG ≥ 10 + 15 < ECTS ≤ 22 = "Décision Conseil"

✓ Statut affects rescue conditions
  → "Ancien": rescue at MG ≥ 9.7
  → "Nouveau": rescue at MG ≥ 9.5

✓ Decisions calculated automatically
  → After import, application calculates decision for each student
  → Results displayed in DataGrid with color coding


FILE FORMAT NOTES
════════════════════════════════════════════════════════════════════════

Decimal separator:  Both comma (,) and period (.) are supported
                   Examples: 12.43 or 12,43 both work

Quoted fields:      If field contains comma, wrap in quotes
                   Example: "Last, Jr",First,ID,...

Empty file:        Must have at least header + 1 data row

Column count:      Minimum 9 columns required
                   Additional columns are optional with defaults


TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

Error: "Extension 'csv' is not supported"
→ Solution: Save file as .csv (not .txt or other format)

Error: "Nombre de colonnes insuffisant"
→ Solution: Ensure CSV has at least 9 columns (id_etudiant through moyenne_generale)

Error: Row X contains non-numeric value in ECTS
→ Solution: Check ECTS column - must be number or empty (not text)

Error: File contains non-numeric value in moyenne_generale
→ Solution: Check MG column - must be decimal number

Empty DataGrid after import
→ Solution: Check if CSV file has data rows (not just header)

DECISION LOGIC (Quick Reference)
════════════════════════════════════════════════════════════════════════

MG ≥ 10:
├─ ECTS ≤ 15        → Admis
├─ 15 < ECTS ≤ 22   → Décision Conseil
└─ ECTS > 22        → Admis avec modération

MG < 10:
├─ ECTS > 22        → Redouble / Exclu
├─ ECTS ≤ 22        → Conseil d'École
│  └─ UNLESS:
│     ├─ Ancien + MG ≥ 9.7        → Admis avec modération (Rachat)
│     ├─ Nouveau + MG ≥ 9.5       → Admis avec modération (Rachat)
│     └─ MoyenneUE ≥ 7 + MG ≥ 8.0 → Admis avec modération (Rachat UE)
└─ Else             → Conseil d'École

SUPPORT
════════════════════════════════════════════════════════════════════════

If you encounter issues:

1. Check CSV file format
   └─ Open with text editor to verify structure

2. Verify column headers match exactly
   └─ Case-sensitive: id_etudiant (not ID_ETUDIANT)

3. Ensure decimal numbers use correct separator
   └─ Both 12.43 and 12,43 are supported

4. Check for extra spaces or hidden characters
   └─ Use "Find and Replace" to clean data

5. Verify file is actually .csv
   └─ Not .txt, .xls, or other format
