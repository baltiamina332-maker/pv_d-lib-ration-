FLUX DE DONNÉES:
────────────────

┌──────────────────────────────────────────────────────────────────────────────┐
│  IMPORT EXCEL                                                                │
│                                                                              │
│  User selects file                                                          │
│       ↓                                                                      │
│  ExcelImportService.ImportData()                                            │
│       ↓                                                                      │
│  List<Etudiant> etudiatsActuels (stored in MainWindow)                      │
│       ↓                                                                      │
│  Display in DataGrid with 9 columns                                         │
└──────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌──────────────────────────────────────────────────────────────────────────────┐
│  CALCUL AUTOMATIQUE (pour chaque étudiant)                                   │
│                                                                              │
│  For each Etudiant in etudiatsActuels:                                      │
│      etudiant.CalculerDecisionEtMention()                                   │
│      {                                                                       │
│          if (MG >= 10)                                                       │
│              if (ECTS <= 15)        Decision = "Admis"                      │
│              else if (ECTS <= 22)   Decision = "Décision Conseil"           │
│              else                   Decision = "Admis avec modération"      │
│          else                                                                │
│              if (ECTS > 22)         Decision = "Redouble/Exclu"             │
│              else                   Decision = "Conseil d'École"             │
│              {                                                               │
│                  if (VerifierRachat())                                       │
│                      Decision = "Admis avec modération"                     │
│              }                                                               │
│          Mention = ObtenirMention()                                          │
│      }                                                                       │
│                                                                              │
│  DataGrid updates with Decision and Mention columns                         │
└──────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌──────────────────────────────────────────────────────────────────────────────┐
│  GÉNÉRER PV WORD (BtnGenererPVWord_Click)                                    │
│                                                                              │
│  MainWindow.GenererPVWord()                                                 │
│      ↓                                                                       │
│  wordService.GenererPV(etudiatsActuels, folder, filename, classeGroupe)    │
│      ↓                                                                       │
│  WordGenerationService.cs:                                                  │
│      1. Create FileStream                                                   │
│      2. Create WordprocessingDocument                                       │
│      3. AjouterEntetePV() - Logo, titre, infos                              │
│      4. AjouterTableauEtudiants() - Tous les étudiants                       │
│      5. AjouterResume() - Statistiques                                       │
│      6. AjouterSignatures() - Lignes signatures                              │
│      7. Save document                                                       │
│      ↓                                                                       │
│  Return path to generated file                                              │
└──────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌──────────────────────────────────────────────────────────────────────────────┐
│  ARCHIVAGE ET DATABASE                                                      │
│                                                                              │
│  archiveService.ArchiverPV(filePath, classe, etudiants, session)            │
│      ↓                                                                       │
│  1. Copy to Documents\PV_Archives\PV_ClasseGroupe_DateTime.docx              │
│      ↓                                                                       │
│  2. EnregistrerDansBaseDeDonnees()                                           │
│      {                                                                       │
│          nb_admis = count(Decision contains "Admis")                        │
│          nb_ajournes = count(Decision contains "Ajourné" or "Redouble")    │
│          INSERT INTO deliberations                                          │
│          (date_deliberation, nb_etudiants, nb_admis, nb_ajournes,           │
│           fichier_pv, utilisateur_id)                                        │
│      }                                                                       │
│      ↓                                                                       │
│  Display success message with file path                                     │
│      ↓                                                                       │
│  Option to open file in Word                                                │
└──────────────────────────────────────────────────────────────────────────────┘
